# Perry Auth API

API-сервіс для автентифікації та керування обліковими записами користувачів у системі **Perry**.

Сервіс відповідає за реєстрацію користувачів, підтвердження електронної пошти, авторизацію, керування access/refresh токенами, відновлення пароля та перевірку стану сервісу.

## Доступні endpoints

| Метод  | Endpoint                             | Опис                                                                                                                         |
| ------ | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `POST` | `/api/auth/register`                 | Розпочинає реєстрацію нового користувача: приймає основні дані облікового запису та ініціює підтвердження електронної пошти. |
| `POST` | `/api/auth/verify-email`             | Перевіряє 6-значний код підтвердження та підтверджує електронну пошту користувача.                                           |
| `POST` | `/api/auth/resend-verification-code` | Генерує та повторно надсилає новий код підтвердження, якщо попередній код не був отриманий або втратив чинність.             |
| `POST` | `/api/auth/complete-registration`    | Завершує процес реєстрації після підтвердження email та зберігає додаткові дані користувача, зокрема ім'я та прізвище.       |
| `POST` | `/api/auth/login`                    | Авторизує користувача за його обліковими даними, повертає access JWT та створює refresh-сесію.                               |
| `POST` | `/api/auth/refresh`                  | Оновлює авторизаційну сесію та видає новий access token за допомогою чинного refresh token.                                  |
| `POST` | `/api/auth/logout`                   | Завершує поточну refresh-сесію та робить подальше використання відповідного refresh token неможливим.                        |
| `GET`  | `/api/auth/me`                       | Повертає основну інформацію про поточного користувача на основі його access token.                                           |
| `POST` | `/api/auth/forgot-password`          | Запускає процес відновлення пароля та надсилає користувачу код підтвердження.                                                |
| `POST` | `/api/auth/reset-password`           | Перевіряє код відновлення та встановлює новий пароль для облікового запису користувача.                                      |
| `GET`  | `/api/health`                        | Перевіряє, чи запущений API та чи може сервіс обробляти запити.                                                              |
| `GET`  | `/api/health/database`               | Перевіряє доступність PostgreSQL та працездатність підключення сервісу до бази даних.                                        |
